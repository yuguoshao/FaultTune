# 多个弱串扰的累积与并行验证

日期：2026 年 11 月 2 日。承接[第一轮局部验证研究](LOCAL_VALIDATION_RESEARCH.md)。

本轮解决了一个具体缺口：即使每个远端影响都不足以单独抵消局部收益，它们的总和也可能使修改有害。逐个寻找“大异常”的检验会漏掉这种累积；直接检验总损失可以在明确假设下控制错误。完整实验还否定了本轮一个预期：当前自适应分组方法在所有测试场景中，都比合并读数的简单方法消耗更多轮次和对象观测。

这不是原创算法或“国际领先”的证据。静态均值、独立向量反馈和合法测量子集的组合，已落入已有组合纯探索框架。继续推进的价值，在于找出真实电路上下文中，当前静态、均值不依赖测量上下文的 oracle 假设是否失效。即使该假设失效，也仍需检查更广的已有理论能否覆盖新问题。

| 本轮产物 | 状态与范围 |
| --- | --- |
| 多个弱影响击穿单影响检验 | 整数概率计算给出有限事件反例；Monte Carlo 独立复核 |
| 检验总损失的置信证书 | 有证明；独立、平稳、已知基线和收益，固定候选 |

| 同一证书的批量测量调度 | 有逐路径等价论证和实现测试；需要分布与调度无关 |
| 门保真度、逻辑错误率或硬件加速 | 本轮未验证 |

## 模型与成本

候选参数修改已经固定，已知局部收益为 a>0。N 个远端监测对象的已知旧基线均为 p0，新参数下的未知坏事件概率为 p_j。目标是判断加性代理损失

\[
\Delta(p)=\sum_{j=1}^N(p_j-p_0)-a
\]

的符号。Δ<0 时接受修改，Δ>0 时拒绝修改。这里不再限制受影响对象的数量、位置或强度，理论允许任意 p_j∈[0,1]。Δ=0 不要求有限时间内决定。

公开冲突图规定哪些对象不能同时观测。一次动作选择非空独立集 S，返回每个 j∈S 的一个 Bernoulli 读数。各对象与各次读数独立；**同一对象的分布不随本次同时观测哪些其他对象而改变**。图只约束动作合法性，不在统计模型中制造相关性。

分别记录三个成本：一次合法动作计一轮；返回的每个比特计一个对象观测；相邻两次动作不同计一次切换，第一次动作不计。Python 运行时间另行记录，不能当成设备耗时。若实际设备需要权重或固定开销，应另行定义总成本，不能把轮数直接称为 shots。

实现中的公开分组是图的一个确定性贪心着色，各组互不重叠、覆盖全部对象。三个有效策略只使用这些完整组；oracle 本身允许任意合法独立集。因此，对这些策略的比较不等于对所有图调度算法的优化。

本轮默认 N=16、p0=0.1、a=0.3、δ=0.05。基线和收益的估计成本视为已支付且数值准确。未知基线、收益不确定性、多次候选选择、漂移、同轮相关读数都没有被本轮保证覆盖。

## 反例：每个影响都小，总损失仍然变坏

上一轮的 `harm_boundary_scan` 针对单个未知有害影响，使用 p0+a=0.4 作为抵消收益的边界。每个对象单独积累似然比，超过 N/δ 则拒绝，低于 δ 则清除此对象；全部对象清除后接受。

考虑四个对象的概率从 0.1 升到 0.2，其他对象不变。每个影响只有 0.1，但总变化是 4×0.1−0.3=+0.1。再考虑全部 16 个对象升到 0.1375，总变化是 16×0.0375−0.3=+0.3。这两种修改都有害。

| 有害场景 | 旧检验误接受，100 次 | 边际 95% Wilson 区间 | 512 步/对象的严格误接受下界 |
| --- | ---: | ---: | ---: |
| 四处弱影响，同一色组集中 | 37/100 | 28.18%—46.78% | ≥44.8795349923% |
| 四处弱影响，分散到色组 | 37/100 | 28.18%—46.78% | ≥44.8795349923% |
| 全部对象微弱变坏 | 81/100 | 72.22%—87.49% | ≥78.3088555418% |

这里的旧检验作为超出适用范围的对照，不把失败归因于其原来的单影响保证。在无远端变化的 null 中，它错误拒绝 2/100 次；null 的理论保证并未因增加对照场景而改变。

反例还可以不依赖 Monte Carlo 或浮点概率。单对象 t 次观测中出现 s 个 1 时，似然比恰为

\[
L(t,s)=4^s(2/3)^{t-s}=\frac{2^{t+s}}{3^{t-s}}.
\]

因此清除边界与拒绝边界分别由整数比较

\[
20\,2^{t+s}\le3^{t-s},\qquad
2^{t+s}\ge320\,3^{t-s}
\]

精确判定。对有理参数 p=r/d，用整数权重动态规划到有限 H，求得“在 H 步内先碰到清除边界”的概率 ℓ_H(p)。清除、拒绝和存活三类质量按共同分母 d^H 保存，总和严格为 1。

独立流使得

\[
P(\text{误接受四弱影响})\ge \ell_H(1/5)^4\ell_H(1/10)^{12},\qquad
P(\text{误接受全体弱影响})\ge \ell_H(11/80)^{16}.
\]

这些是有限事件的严格下界，非无限时域估计。若预算至少容纳 NH 次单点观测，同一事件也保证在预算内误接受。精确有理数及向下截断的十进制下界见[解析结果](../experiments/local_validation/results/aggregate_analytic.json)，计算与独立小实例枚举见[数学实现](../experiments/local_validation/aggregate_math.py)及其测试。

## 正确的证书：直接控制总和

### 异质 Bernoulli 读数可以合并

设大小为 m 的组已经完整读取 n 次，得到总和 K，组内平均概率为 q̄。对任意实数 λ，凹函数 p↦log(1−p+p exp λ) 给出

\[
E[e^{\lambda K}]
=\prod_{j\in S}(1-p_j+p_j e^\lambda)^n
\le(1-\bar q+\bar q e^\lambda)^{nm}.
\]

Chernoff 方法因此得到，令 q̂=K/(nm)，

\[
P\{nm\,\mathrm{kl}(\hat q,\bar q)>\beta\}\le2e^{-\beta}.
\]

这里 kl 使用自然对数。它不要求组内 p_j 相同，但需要独立性及每个对象等长的观测前缀。对任意 α，将 β 取为 log(2/α)，反演上述不等式得到平均概率的上下界。

### 两种证书与三种策略

`sweep_kl` 每次完整遍历所有组，使每个对象的计数相同。在完整遍历次数 n=2^k 处，合并全部 Nn 个比特，仅用一个总均值区间。分配

\[
\alpha_k=\frac{\delta}{(k+1)(k+2)},\qquad
\sum_{k\ge0}\alpha_k=\delta.
\]

将均值区间乘 N，再减 Np0+a，即得 Δ 的区间。物理上要分组读出，不意味着统计上必须分别判断每组。

`group_kl_balanced` 与 `group_kl_adaptive` 则在每组的 n_g=2^k 检查点建立区间，分配

\[
\alpha_{g,k}=\frac{\delta}{G(k+1)(k+2)}.
\]

乘以各组大小、相加、再减 Np0+a，得到总变化区间。balanced 优先补齐计数最少的组；adaptive 优先补齐“当前组区间宽度 / 下一次加倍需要的轮数”最大的组。这只是对当前矩形证书的启发式，不是信息最优算法。

同时覆盖事件的概率至少 1−δ。可以预先为每组生成无限随机流，因此即使选择下一组依赖已有数据，同一个同时覆盖事件仍然约束所有实际访问的检查点。三种策略都只在总上界<0 时接受、总下界>0 时拒绝；由此对每个固定 p，任一错误决定的概率至多 δ。

预算中断时，已发生的部分测量照常计费，只保留最近完整检查点的证书并返回 `abstain`。不把弃权算作正确，也不把“已经作决定的运行中的错误率”当成保证对象。没有预算时，非零间隙下区间会收缩并最终决定；Δ=0 无有限终止承诺。

**不能直接合并不同采样次数的异步组。** 那样估计的是按采样次数加权的均值，而非所需的对象总和。改善异步证书需要联合置信域或有效的重新加权论证。

实现对 KL 端点使用向外的二分括区间并额外放宽 10⁻¹²。统计证明在实数模型下成立；该浮点实现经过数学测试，但不是形式化验证的数值库。

## 完整实验：简单合并优于当前自适应方法

每种 path/star 场景对每个策略运行 100 次，轮数和对象数预算均为 262,144。四弱影响的位置分别为 {0,2,4,6} 与 {0,1,14,15}；“集中”是针对路径图色组的定义，星图沿用同一概率向量，不重新挑选有利位置。

路径图分为两个大小为 8 的组。下表是平均轮数；三个有效策略每轮均读取 8 个对象，对象成本为表值的 8 倍。

| 场景 | 合并 sweep | 分组 balanced | 分组 adaptive |
| --- | ---: | ---: | ---: |
| 无远端变化，Δ=−0.3 | 899.20 | 1,649.92 | 1,583.36 |
| 四弱影响集中，Δ=+0.1 | 9,108.48 | 16,240.64 | 16,240.64 |
| 四弱影响分散，Δ=+0.1 | 9,451.52 | 16,896.00 | 17,571.84 |
| 全部微弱变坏，Δ=+0.3 | 948.48 | 1,820.16 | 1,894.40 |

合并方案相对 adaptive 的平均轮数/对象成本低 43.2%—49.9%。所有有效策略均未观察到错误；四弱影响集中场景中，两种分组方法各有 1/100 次弃权，合并方法没有弃权。

星图分组大小为 1 与 15。轮数与对象成本必须分别比较：

| 场景 | sweep 轮数 / 对象数 | balanced 轮数 / 对象数 | adaptive 轮数 / 对象数 |
| --- | ---: | ---: | ---: |
| null | 899.20 / 7,193.60 | 1,344.00 / 10,053.12 | 1,192.96 / 13,701.12 |
| 四弱影响集中 | 9,108.48 / 72,867.84 | 14,469.12 / 106,076.16 | 11,904.34 / 137,564.14 |
| 四弱影响分散 | 9,451.52 / 75,612.16 | 14,305.28 / 108,492.80 | 12,472.32 / 145,510.40 |
| 全部微弱变坏 | 948.48 / 7,587.84 | 1,442.56 / 11,011.84 | 1,101.44 / 13,161.60 |

adaptive 相对 balanced 节省 11.2%—23.6% 的平均轮数，却增加 19.5%—36.3% 的对象观测。更重要的是，它在四种场景的两项成本上仍然均高于 sweep。adaptive 在四弱影响集中场景弃权 1/100 次；其他星图单元格没有弃权，均未观察到错误。

小样本预试验曾显示星图 adaptive 可能优于 sweep；完整结果没有支持这个判断。该预试验不能与本表混用。

每个 100 次试验的零错误单元格，边际 95% Wilson 错误率上限仍约为 3.70%。这不是“证明错误率为零”，也不是所有单元格的同时置信结论。理论保证来自前述覆盖证明；模拟只检查这些特定实例和实现。跨图、策略和场景共享随机流，也不能当作相互独立的重复证据。

### 图改变轮数，不自动减少对象观测

另对 null 与四弱影响集中场景，各用 30 个相同随机种子比较空图、路径图和完全图，共 180 次 sweep 试验。60 组跨图配对中，决定、对象计数和置信区间逐项一致；轮数严格为 1:2:16。

这是该 oracle 和均衡 sweep 的逐路径性质：并行改变每个完整遍历需要多少轮，但不改变同一对象第 k 个读数。不能据此声称实际量子器件上的并行门具有相同噪声分布。

### 消除不必要的组切换

原始 sweep 每遍历一次就轮换所有组，G>1 时结束于 n 次遍历的切换数为 Gn−1。但证书只在 1,2,4,… 处检查，可以在每个检查点之前先连续读完第一组的新增前缀，再读第二组，以此类推。

在无预算中断、分布平稳且不依赖动作的条件下，`sweep_kl_batched` 与原始 sweep 在每个检查点看到每个对象完全相同的前缀。因此决定、区间、对象数和轮数逐路径相同，而切换数降为

\[
G(1+\log_2 n)-1\quad(G>1),
\]

G=1 时为 0。比如 G=2、n=4096，切换数从 8191 降到 25。[批量调度实现](../experiments/local_validation/batched_sweep.py)和测试保留了旧实验源码哈希；本轮表格记录的是原始 sweep，批量版本没有另行计入 Monte Carlo 样本量。

预算恰好打断区块时，两种调度已购买的部分前缀可能不同，不能宣称逐路径成本仍完全一致。两者都只使用最后一个完整检查点证书。

## 信息下界：能证明什么

### 任意合法动作族

设动作 e 观测集合 S_e，其在 p 与 q 下的一轮信息为

\[
d_e(p,q)=\sum_{j\in S_e}\mathrm{kl}(p_j,q_j).
\]

对在全部非零 Δ 实例上终止且 uniformly δ-correct 的验证器，选择任何符号相反的 q，由停止转录的换测度和二元数据处理，

\[
\sum_e E_p[N_e]d_e(p,q)\ge\kappa_\delta,
\qquad \kappa_\delta=\mathrm{kl}(1-\delta,\delta).
\]

归一化期望动作次数得到

\[
I^*(p)=\sup_{w\in\Delta(\mathcal E)}
\inf_{q:\Delta(q)\Delta(p)<0}\sum_e w_e d_e(p,q),
\qquad E_pT\ge\frac{\kappa_\delta}{I^*(p)}.
\]

这是经典信息分配下界。一个数值可行分配仅给 I* 的下界，把它直接放进分母会夸大采样下界；本轮没有这样使用数值优化。

### 任意不等大小的不相交完整组：null 的精确刻画

现在固定动作族仅为 G 个完整不相交组，大小为 m_g，总和 N；真实 p_j=p0，且 0<a<N(1−p0)。记 d(q)=kl(p0,q)。存在唯一 z>0 及 q_g>p0 满足

\[
m_gd(q_g)=z\quad\forall g,
\qquad \sum_g m_g(q_g-p_0)=a.
\]

此时 **I*=z**。组内 Jensen 不等式先把任意替代模型缩成组均值。对任意分配 w，同一个边界替代 q_g 给信息 ∑w_g z=z，因此 I*≤z。再取

\[
w_g\propto\frac1{d'(q_g)},\qquad
d'(q)=\frac{q-p_0}{q(1-q)}.
\]

加权 KL 关于 q 严格凸，以上分配满足总和约束的 KKT 条件，使该替代达到内层全局最小值 z，所以 I*≥z。坏实例的开半空间下确界可由边界任意逼近。单调性给出解的存在唯一性。

等大组 m_g=m 时，q_g=p0+a/N，故 I*=m kl(p0,p0+a/N)。本轮数值锚点为：

| null 动作族 | 信息率 I* | 期望轮数下界 |
| --- | ---: | ---: |
| 路径图所用两个完整色组 [8,8] | 约 0.01410434 | 约 187.8851 |
| 星图中心与全叶组 [1,15] | 约 0.01842487 | 约 143.8271 |

星图最优轮分配约为 (0.23947, 0.76053)，对应最难替代组均值约 (0.16717, 0.11552)。对于一轮成本，星图任意叶子子集被全叶组的信息支配，所以这一轮数刻画也覆盖其全部合法独立集。这个支配关系**不适用于对象成本**；对一般图，不能把固定着色的结果当成所有独立集的精确最优值。

对于对象成本，统一边界替代 q_j=p0+a/N 对任意动作都给出每对象相同的 KL，故 null 下还有通用界

\[
E_0[\text{objects}]\ge
\frac{\kappa_\delta}{\mathrm{kl}(p_0,p_0+a/N)}
\approx1503.0806.
\]

这些 null 下界不适用于四弱影响的非 null 实例。带预算且允许弃权的算法也不能直接套用要求完整决定的下界，故不把表中成本除以上述数字解释为严格近似比。

## 与已有工作的关系

[Jourdan 等，ALT 2021，Efficient Pure Exploration for Combinatorial Bandits with Semi-Bandit Feedback](https://proceedings.mlr.press/v132/jourdan21a.html) 已研究组合动作、逐分量反馈、答案识别与信息分配。将每对象读数减去 c=p0+a/N，取答案集合为 {空集，全部 N 个对象}，两答案的期望收益差恰为 Δ；测量动作取冲突图独立集。均值平移后仍可用已知平移的 Bernoulli 族表示。因此本轮静态问题直接落在这个范式内，不能仅凭“总损失+冲突图+自适应采样”声称新问题。

[Howard 等，Annals of Statistics 2021，Time-uniform, nonparametric, nonasymptotic confidence sequences](https://arxiv.org/abs/1810.08240) 给出更一般的时间一致推断工具。本轮只是简单几何检查点加可求和错误预算，尚未追求最紧的联合证书。

[Fiez 等，2019，Sequential Experimental Design for Transductive Linear Bandits](https://arxiv.org/abs/1906.08399) 是信息分配的相关背景，但标量线性反馈与这里的逐对象向量反馈需要区分。[Russo 等，AISTATS 2025](https://proceedings.mlr.press/v258/russo25a.html) 的反馈图同样不能未经转换就等同于同时测量的冲突图。

本轮新增的是 FaultTune 的反例、明确假设、可执行证书和成本审计材料；不是对上述通用理论的优先权主张。

## 下一轮只验证一个更关键的问题

建议暂不继续为这个静态模型增加调度算法。下一轮做一个可被推翻的最小电路任务：**能否找到两个物理定义一致的模型，在现有校准动作下完全不可区分，却对合法目标 workload 的修改效果给出相反符号？**

最小假设形式为：候选有局部收益 a，背景门活动 x=1 时才激活未知远端损失 h>a。模型 M0 的变化为 −a，M1 为 −a+hx；现有校准菜单只运行 x=0，目标 workload 运行 x=1。若两模型在全部校准动作上的完整观测分布相同，任何自适应验证器的接受概率也相同，不可能同时满足好模型接受概率≥1−δ和坏模型接受概率≤δ（δ<1/2）。这是标准不可辨识论证。

真正需要产出的是：一个合法的小电路及噪声模型、明确可观测的目标、严格缺失的上下文观测，以及加入一个匹配上下文的审计动作后解除歧义的成本。先限定待搜索的小电路与噪声模型族；只有解析论证或穷尽检查排除该族的全部实例，才能否定该族中的分离。普通搜索失败只能记为“未找到支持”，据此决定是否暂不沿此推进。

修复方案必须对照直接 workload A/B 审计。在同等错误保证、好候选接受能力或完成率约束下，比较主动寻找未知影响对象的成本；总成本权重需预先定义，也可分别报告运行、读出和切换成本，避免更常拒绝或弃权制造低成本。要区分选择读出哪些对象与改变驱动上下文，不能把图中非法的测量并发偷偷用作目标 workload，也不能把代理错误率直接命名为保真度。
