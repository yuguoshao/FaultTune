# FaultTune 首轮电路验收的文献定位与下一项检验

日期：2026 年 11 月 3 日。本文依据本轮已核对的原始文献和冻结设计撰写。正式实验的结果与审计尚待完成，本文不预判挑战是否通过，不修改预登记。权威实验配置为 [confirmation_spec_v1.json](../experiments/circuit_validation/confirmation_spec_v1.json)，SHA256 为 `ab2c711aacca68e84972ac5f6163a08bbc2f3e64544f90d26c9777904e146235`。

FaultTune 当前建立的是一个可审计的研究底座：固定候选参数后，直接检验目标电路是否受益，并将物理模型、统计错误、预算内决定能力和观测成本分开核验。这里采用的顺序检验、信息分配和在线学习技术均有明确先行工作。现阶段可主张模型与实现的具体性质，尚无依据主张一种新的通用校准算法或国际领先的校准性能。

## 1. 当前贡献应写到什么程度

本轮的物理对象是一个静态三比特模型族。Hamiltonian 包含受控比特的 X 旋转和另外两比特的固定受控相位；候选同时改变控制幅度与作用时长。读出翻转和可选退相干通过显式通道处理。目标是预先固定上下文分布下输出非 000 的概率变化，old/new 两侧概率均未知且观测均收费。

这一模型能严格展示：局部校准菜单中的完整观测分布可以相同，而另一上下文的任务变化方向相反。其意义是指出特定观测菜单的不可辨识性。受控比特与另外两比特在本模型中并未产生纠缠；额外损失来自共同作用时长改变了另一对比特的相位积累。因此不宜把它描述为一般的远程未知串扰发现，更不能据此推断任意处理器的校准都会失败。适用的混合 workload 权重也须明确，不能把单一上下文的符号直接推广到所有混合权重。

统计实现提供了原始计数、合法动作、费用与停止证书的可重放记录。联合 Beta 混合 GLR 的错误控制在规定独立观测、静态分布和固定候选条件下成立；数值停止使用向外包围计算。它是经典混合鞅方法的具体专化，尚未证明这套有限预算实现最优。

确认矩阵包含 36 个主要效率实例和 8 个诊断实例，来自同一个三比特物理模型族。三组噪声配置不是三个独立设备，多个 ε 也不是处理器规模扩展。正式运行若完整，只能支持这套冻结模型和比较口径内的结论。实验设计、已完成的单元验证与尚待完成的性能判定应分别表述。

## 2. 与相关工作的关系

| 先行工作 | 它解决的问题 | 对 FaultTune 的约束与用途 |
| --- | --- | --- |
| Snake Optimizer，Klimov 等，2020；后续 68 比特研究，2024 | 在硬件约束和物理误差模型下生成、优化及局部修复控制参数 | 提供候选生成与校准流程。固定候选验收可以接在其后；本轮没有比较整个优化器，也没有运行完整 Snake 闭环 |
| Simultaneous GST，Rudinger 等，2021 | 在并行门环境中表征、区分并诊断串扰误差 | 上下文依赖和校准情境失配已有实验先例。完整过程表征通常提供比任务符号更多的信息；能否用较少数据可靠判定指定任务需要另行证明 |
| Track-and-Stop，Garivier–Kaufmann，2016；混合鞅一般假设检验，Kaufmann–Koolen，2021 | 固定置信纯探索、信息最优分配、联合 GLR 与时间一致阈值 | 当前有限上下文、独立 Bernoulli 臂、已知线性目标适用这些工具。`joint_trackstop` 是相应专化，不能算新统计框架 |
| CombGame，Jourdan 等，2021 | 动作与答案可以不同的组合纯探索；独立指数族分量、最佳响应与在线学习采样 | 把旧/新上下文当作臂、把两种目标比较当作答案即可建立对应。当前单臂动作使组合 oracle 很简单；不能因问题带有量子上下文就排除它 |

### Snake：候选质量与验收成本是不同指标

Snake 的重点是如何利用图上的局部结构，在大控制空间中找到好的参数。2020 年工作展示其在 53 比特处理器中的应用；2024 年工作进一步在 68 比特处理器上优化频率轨迹，并讨论向逻辑比特规模延伸。文献中的性能改善、优化耗时或局部修复收益，不能与本轮“固定候选的验收 shots”互相替代。

FaultTune 可以把验收作为提交 Snake 局部更新前的一道关。要进一步声称整个校准更快，还必须支付生成候选、重新测量旧参数、失败更新、重新优化和验证的全部成本，并固定最终任务质量；本轮并未做这项端到端比较。仓库的 Rust/Python Snake 设计与本轮 Python 验证实验也应分别报告状态。

### Simultaneous GST：已经知道的现象与尚待解决的任务

Rudinger 等在离子阱和超导平台上展示了上下文相关的门误差，并用同时 GST 区分不同误差结构。它已经足以否定“观察到并行上下文改变门表现就是新现象”的定位。

本轮仅校准上下文的盲区对照，展示的是一个更窄的逻辑问题：在给定观测菜单下，目标更新方向是否可辨识。GST 的完整门模型估计与这种二元任务判断所需信息不同。若将来声称任务验收比 GST 便宜，必须先对齐观测权限、噪声假设、预表征费用及所要求的输出；不能要求 GST 重建大量无关参数，再把省略这些输出的成本差全部归为算法优势。

### 纯探索：本轮必须面对的直接强对照

记每个 old/new、上下文组合的失败率为一条臂的均值，公开权重组成系数向量 \(a=(-\pi,+\pi)\)。目标就是判断 \(a^\top p\) 的符号。已知权重可以吸收到各臂观测的尺度中，仍然属于指数族观测；独立执行条件也符合对应的纯探索模型。

因此，本轮只重新分配这些臂的独立 shots，不能凭重新命名获得方法新颖性。Neyman 型分配、均衡分配、直接任务配对检验与信息分配策略均有合理地位。直接配对检验还利用了这个二元任务的特定结构，不应被一个形式上更复杂的算法自动替代为“弱对照”。

`combgame_glr` 实现两个答案各自的 AdaHedge 学习器、KL 最佳响应、乐观奖励和比例式 C-tracking。其固定 block 观测、采样端紧化及共用 Beta-GLR 阈值在 [统计方法说明](CIRCUIT_STATISTICAL_METHODS.md) 中逐项列出。这是具有明确修改的实现，不能直接把原文整套渐近最优性定理当作其已证明属性；也不能仅将 `joint_trackstop` 改名就称完成了 CombGame 对照。

## 3. 为什么本轮不足以称为国际领先

“1% 错误、95% 决定能力、3 倍点估计、2 倍置信下界”是 FaultTune 自定的研究门槛。通过它们至多意味着通过一次定义明确的比较；它们不是领域通用认证。当前至少存在以下结论边界：

- 统计部件来自现有方法。需要有实质的新问题结构、定理或可复现的适用范围优势，才能进一步讨论研究创新。
- 三比特静态仿真没有检验真实设备的漂移、非马尔可夫效应、控制约束与大规模调度；Kraus/态矢量一致性只检验指定前向模型。
- 基线属于本轮冻结的可比方法集合。有限集合内胜出不等于排除了全部适用方法；本说明也不是截至某日期的全面文献优先权检索。
- 单个验收器减少 shots，不代表产生候选或完成校准更快；主机上的计数模拟加速也不是量子设备加速。
- 置信界未达到安全或功效门槛时，只能判定资格未确认。尤其名义错误率已接近 1% 时，有限 Monte Carlo 的上界可能超过 1%；这本身不证明理论被违反。

正式结果无论正负，都应保留全部冻结实例、预设对照和成本口径。若成本目标未通过，可得到明确的否定性结论：“这些简单分配策略在本模型内尚未带来所要求的收益。”它不能扩写成所有量子任务验收都没有价值。反过来，即使通过，也不能省去上述范围限制。

## 4. 下一条路线：找出足以判断任务方向的最小补充实验

下一步只推进一个问题：**对明确的量子噪声模型，局部校准之外最少需要补充什么实验，才能可靠判定固定更新对任务的影响；将这些额外实验的费用算入后，是否仍优于直接任务 A/B。**

这条路线保留目前已经得到的盲区构造，同时把研究对象从通用臂分配转到由量子电路限定的观测信息。它不以完整恢复串扰参数为目标，也不预设一定存在节省。

### 4.1 先解决一个可否证的最小模型

下一轮仍使用同样的三比特受控相位结构，先固定同一对 old/new 控制命令，再让相位强度、读出翻转与退相干率在预先声明的参数盒内未知。控制命令不得随隐藏参数重新选择。目标 workload 及 ε 在实验前固定。

实验菜单只增加一个有物理含义的干预族：在原有 spectator 准备之外，允许在受控比特及相位敏感旁观比特上使用预先指定的分析相位，用来观察旋转或相位的另一分量；分析相位先固定为 \(\pi/2\)，不依据验收真值挑选。保留全部三比特输出分布，并给所有比较器相同的输出权限。是否采用该额外干预必须由信息增益和完整费用决定，不能默认多一个线路就是有效的新方法。

可辨识性问题中的审计菜单 \(\mathcal E_{\rm audit}\) 只包含原有 spectator 为 0 的校准线路与上述新分析相位线路，不包含直接测量目标 spectator-plus、原分析基的 old/new 线路。后者仍作为付费后备动作和 A/B 对照保留。这样问的是非目标审计观测能否充分判断任务，而不会因为把目标本身也放进菜单，就得到一个由定义保证的“可辨识性结果”。成本优化的完整菜单可以包含两类动作；如果最优策略仍主要选择直接目标测量，这也是应接受的结论。

第一项任务是寻找反例：在这个有限菜单内，是否仍有两组合法噪声参数产生完全相同的观测分布，却对应相反的目标更新方向。原有“spectator 为 0”的盲区只是起点；增加一个普通目标上下文即可区分那两个既有世界，本身不构成新的研究结果。需要检查整个预定参数盒中的别名、对称性和未知噪声混淆，而非只检查那两个世界。

一个具体的待证机制是：在固定读出噪声底下，小旋转的任务损失可能只具有二次信号，而合适的 quadrature 观测具有一次信号。若两组相反方向参数的相位差为 \(\Theta(\sqrt\varepsilon)\)，原 loss-bit 分布的差异可能只有 \(O(\varepsilon)\)，对应单次 KL 为 \(O(\varepsilon^2)\)；新观测则可能得到 \(\Theta(\varepsilon)\) 的单次 KL。这里使用的是概率远离 0、1 时的局部二次 KL 展开，**尚未证明这类参数对、全部替代参数上的分离，或相应算法复杂度**。它仅给出值得检验的信息尺度差。未知退相干若以一次量进入目标、读出参数若须估到 \(O(\varepsilon)\)，其付费估计就可能耗尽这项潜在收益；不能忽略这些 nuisance 参数后宣布 \(\varepsilon^{-2}\) 到 \(\varepsilon^{-1}\) 的普遍改善。

### 4.2 一个应先写清的引理和成本约束

设 \(P^e_\theta\) 为参数 \(\theta\) 下执行实验 \(e\) 的完整输出分布，\(\Delta(\theta)\) 为目标变化。以下 \(\mathcal E\) 指被检验是否充分的审计菜单。若有 \(\theta_-,\theta_+\) 满足

\[
\Delta(\theta_-)\le-\varepsilon,\qquad \Delta(\theta_+)\ge0,
\qquad P^e_{\theta_-}=P^e_{\theta_+}\quad\forall e\in\mathcal E,
\]

还需明确观测假设：给定过去历史与当前动作 \(e\)，下一观测的条件分布始终为 \(P^e_\theta\)，即采用独立重置的静态实验律；公共初始信息、控制命令与策略随机化在两个世界相同且不携带隐藏参数信息。只知道单次边缘分布相同，而允许跨次相关性不同，并不足够。

在这些条件下，任何只使用 \(\mathcal E\) 中实验的自适应验证器，在两个世界的全部观测转录分布相同。因此它不可能同时满足

\[
\Pr_{\theta_-}(\mathrm{accept})\ge0.95,
\qquad \Pr_{\theta_+}(\mathrm{accept})\le0.01.
\]

证明只需对历史归纳：给定相同历史，下一动作和随机化规则相同，下一观测分布也相同，停止及接受事件因而同分布。无限预算也不能消除这样的盲区。这是标准可辨识性论证，不作为原创引理申报。排除所有这种完全相同的世界仍不等于已经证明有限预算够用，还需要定量分离。

在相同条件观测假设下，若每个实验费用 \(c_e>0\)，固定预算验证器在 \(\Delta(\theta)\le-\varepsilon\) 时接受概率至少 0.95，并且对允许模型内每个 \(\Delta(\lambda)\ge0\) 的参数接受概率至多 0.01，则其在这个 \(\theta\) 下的期望实验次数 \(x_e=\mathbb E_\theta N_e\ge0\) 必须满足

\[
\sum_e x_e\,\mathrm{KL}(P^e_\theta\Vert P^e_\lambda)
\ge \operatorname{kl}(0.95,0.01)
\quad\text{对每个 }\lambda\text{ 使 }\Delta(\lambda)\ge0.
\]

链式 KL 恒等式与接受事件上的数据处理不等式可直接应用于有限预算截断的停止转录；允许弃权，不要求算法永不弃权或无截断终止。由此最小化 \(\sum_ec_ex_e\) 得到一个必要的信息成本下界，并不保证可达。它来自经典停止转录换测度，不是本项目独有的公式。研究工作应落在电路分布是否具有可证明的分离、哪些干预不可省略、以及可实现算法能否接近这条下界，而非只求出一个数值优化解。

### 4.3 做完这项检验再决定是否扩大

这项工作的首个交付应包含：固定的参数盒与有限实验菜单；一个严格的不可辨识反例，或排除相反符号等价世界并给出正信息间隔的证明；以及将初始化、old/new、额外分析线路、模型估计与失败运行全部收费的有限预算比较。数值搜索可以找反例或提出候选界，不能替代参数盒上的证明。

比较时保留直接 A/B，同时给一个通用的、利用相同参数模型的最佳实验设计/联合检验基线。增加了共享噪声参数后，不能只与把所有臂视为互不相关的旧基线比较。若优势完全由通用模型约束解释，应报告为应用专化。若仅在准确已知噪声模型下成立，应明确标为条件结果；未经付费验证的失配界不能免费提供给验收器。

**停止条件也要明确：**若仍存在相反符号的观测等价世界，则给出反例并停止宣称该菜单足够；若可辨识但完整成本无法优于直接 A/B，则保留负面成本结果，结束这条“更便宜验收”的假设。只有同时得到可辨识条件与公平成本收益，才值得增加比特数、接入真实设备或嵌入 Snake 闭环。以上均是下一轮待检验工作，不属于当前冻结实验的结果。
