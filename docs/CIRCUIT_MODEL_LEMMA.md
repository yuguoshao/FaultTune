# 一个具有校准盲区的三量子比特模型

本说明给出一个严格限定的反例：指定校准菜单的全部观测相同，不能保证同一候选修改对目标电路有益。结论在下述哈密顿量和通道模型中可解析证明；它不是实际芯片实验，也不声称所有校准方法都存在相同盲区。数值审计见 `experiments/circuit_validation/results/physics_audit.json`。

## 模型、控制和任务

取三个量子比特 \(q_0,q_1,q_2\)，令 \(\hbar=1\)，时间和频率使用相容的无量纲单位。控制窗口中的固定模型为

\[
H_m(u)=\frac{\omega+u}{2}X_0+\gamma_m P_{11}^{(1,2)},\qquad
P_{11}^{(1,2)}=\frac{I-Z_1-Z_2+Z_1Z_2}{4}.
\]

因此隐藏项是固定的 ZZ 相互作用与固定局部 Z 项的组合，不是按场景指定的失败概率。两个世界仅耦合不同：\(M_0:\gamma_0=0\)，\(M_1:\gamma_1=\omega\)。控制在比较前固定：

\[
\mathrm{old}:(u,\tau)=(0,1),\qquad
\mathrm{new}:(u,\tau)=(-\omega,2).
\]

候选同时改变幅度和时长，是预先写明的解析构造，不通过隐藏的 \(\Delta\) 搜索或筛选。它在两个世界完全相同。此构造尚未实现从有噪校准数据学习候选的优化器。

每个电路从 \(|000\rangle\) 开始。校准场景 `spectator_0` 在 \(q_1\) 上施加 H；目标场景 `spectator_plus` 在 \(q_1,q_2\) 上施加 H。随后执行上述单个控制窗口，撤销准备 H 门，对三个比特全部作 Z 测量。成功当且仅当输出 000，失败指标为任何比特非零。输出索引为 \(q_0+2q_1+4q_2\)。

窗口中的两个哈密顿量项对易，因而

\[
U_m(u,\tau)=R_{x,0}((\omega+u)\tau)\,
\exp(-i\gamma_m\tau P_{11}^{(1,2)}).
\]

它们是同一时间窗口内的演化，不是两个时长相加的串行门。\(q_0\) 与 \(q_1q_2\) 始终保持乘积结构；本例不依赖被调比特与其余比特的纠缠。目标使用全部读出，而候选增长的公共窗口时长改变了 \(q_1q_2\) 的相互作用相位。

## 引理：指定校准菜单无法识别目标改变量的符号

令 \(s=\sin^2(\omega/2)\)，无读出噪声和退相干，且 \(0<s<5/9\)。固定校准菜单

\[
\mathcal C=\{(\mathrm{old},\mathrm{spectator\_0}),
             (\mathrm{new},\mathrm{spectator\_0})\}.
\]

对菜单中的每项，两个世界的完整八结果概率分布完全相同；但对 `spectator_plus` 目标，定义新旧失败率之差 \(\Delta=p_{\mathrm{fail,new}}-p_{\mathrm{fail,old}}\)，有

\[
\Delta(M_0)=-s<0,\qquad
\Delta(M_1)=\frac{s(5-9s)}4>0.
\]

证明如下。校准场景的 \(q_2\) 在整个窗口中为 \(|0\rangle\)，因此 \(P_{11}^{(1,2)}\) 在全部占据子空间上为零；两个世界的末态和完整读出分布一致。这一相同性覆盖所有八个结果，不能通过改用另一读出统计量消除。

目标场景的 \(q_1q_2\) 在窗口前为 \(|++\rangle\)。记 \(t=\sin^2(\gamma_m\tau/2)\)。受控相位后撤销两个 H，四结果概率为

\[
(P_{00},P_{01},P_{10},P_{11})=(1-3t/4,t/4,t/4,t/4).
\]

\(q_0\) 的旧控制失败概率为 \(s\)，新控制失败概率为零。\(M_0\) 的配对比特始终成功，所以 \(\Delta(M_0)=-s\)。\(M_1\) 的旧配对成功概率为 \(1-3s/4\)，新配对失败概率为 \(3\sin^2\omega/4=3s(1-s)\)，于是

\[
p_{\mathrm{fail,old}}(M_1)=1-(1-s)(1-3s/4),\qquad
p_{\mathrm{fail,new}}(M_1)=3s(1-s),
\]

相减即得引理。

特别地，\(\omega=\pi/3\) 时：

| 世界 | 目标旧失败率 | 目标新失败率 | \(\Delta\) |
| --- | ---: | ---: | ---: |
| \(M_0\) | \(1/4\) | \(0\) | \(-1/4\) |
| \(M_1\) | \(25/64\) | \(9/16\) | \(11/64\) |

\(M_1\) 的目标完整分布分别为

\[
P_{\mathrm{old}}=(39,13,3,1,3,1,3,1)/64,\qquad
P_{\mathrm{new}}=(7,0,3,0,3,0,3,0)/16.
\]

`physics_audit.py` 从 \(\sin^2(\pi/6)=1/4\)、\(\sin^2(\pi/3)=3/4\) 出发，以 `Fraction` 完成这些值的精确有理运算，再独立与态矢量实现比较。浮点比较和精确等式分别记录。

## 统计含义和菜单边界

设验证器只得到相同的公共控制信息、相同的公共随机化规则，以及菜单 \(\mathcal C\) 中付费获得的观测；隐藏模型标识、\(\gamma_m\) 和评分器真值均不可见。即使验证器自适应选择 old/new、随机停止或采集任意多次观测，其完整观测历史分布在两个世界仍相同。证明是对历史长度归纳：同一历史下行动规则相同，所选行动的条件观测分布也相同。

因此接受候选事件 A 满足 \(\Pr_{M_0}(A)=\Pr_{M_1}(A)\)。若有害世界要求误放行概率至多 \(\alpha\)，则有益世界的接受概率也至多 \(\alpha\)；不能同时达到有益更新 95% 通过率和有害更新 1% 误放行率。允许弃权不改变这个接受概率约束。

这是指定准备方式、控制菜单和可见信息下的不可辨识性。允许将 \(q_2\) 准备为 \(|+\rangle\)、使用新的表征电路或读取额外物理信息，便可能打破相同性。直接在目标场景作独立付费 A/B 观测就是本项目考虑的解决方式；本引理本身不证明该方式具有某个成本加速比。

## 噪声扩展与目标权重

实现允许在控制窗口内对 \(q_1,q_2\) 分别施加固定速率 \(\kappa\ge0\) 的马尔可夫退相干，通道为

\[
\mathcal D_\tau(\rho)=(1-p_Z)\rho+p_ZZ\rho Z,\qquad
p_Z(\tau)=\frac{1-e^{-\kappa\tau}}2.
\]

其 Kraus 算符为 \(\sqrt{1-p_Z}I,\sqrt{p_Z}Z\)，与窗口演化对易，故在窗口末施加是该模型内的精确实现。撤销 H 后，三个读出分别以概率 \(r\) 翻转；Kraus 算符为 \(\sqrt{1-r}I,\sqrt rX\)。这些通道在合法参数下均为 CPTP。退相干的 old/new 强度必须分别使用 \(\tau=1,2\)，不能把同一噪声概率强加给两个窗口。

上述通道保持校准场景中 \(q_2\) 的零子空间直到末端读出，因此校准完整分布仍对隐藏耦合完全盲。任意噪声参数并不保证目标异号；审计网格不会根据异号真值筛选模型。

当 \(\kappa=0\)，记 \(q=1-r\)，可得

\[
\Delta(M_0)=-(1-2r)sq^2,\qquad
\Delta(M_1)=(q-1/2)s\,[q(q+3/2)-2(q+1/2)^2s].
\]

默认 \(\omega=\pi/3,r=0.01,\kappa=0\) 时，两世界的校准旧/新失败率均为 0.2698255 / 0.029701。目标 \(M_0\) 的改变量为 −0.2401245；目标 \(M_1\) 的旧/新失败率为 0.405806625 / 0.57180025，改变量为 +0.165993625。这些非零读出基线避免依靠无噪声零失败率作为唯一示例。

若改为混合目标，令 `spectator_plus` 占比为 \(w\)，必须重新使用混合目标的 \(\Delta\)。无噪声时

\[
\Delta_w(M_1)=s\left[-1+\frac94w(1-s)\right].
\]

在 \(\omega=\pi/3\) 处异号要求 \(w>16/27\)；默认读出噪声下要求 \(w>39204/66305\approx0.5912676269\)。默认参数的等权混合给出 \(\Delta_{1/2}(M_1)=-0.0370654375\)，仍然改善，不能引用单场景引理称其有害。场景权重应在正式实验前固定。

## 实现与证据范围

物理实现为 `quantum_model.py`；付费观测接口 `observation.py` 只交付上述完整分布经失败判据得到的 loss bit，两个被比较方法都使用同一观测协议。old/new 测量噪声独立，公共场景可以共享；不能通过模拟器内部随机数构造免费的物理耦合样本。

每次 old/new 执行均各计一次电路，控制窗口时长分别为 1 和 2。H 门在物理模型中理想且瞬时，重置理想；准备、读出、重置和切换的额外时间是独立成本模型，不能误写成已模拟真实有限时长脉冲的演化。

本构造支持“局部菜单信息不足，需要面向目标的验收”这一动机，以及软件观测接口的可复现检查。它尚不支持真实设备保真度、漂移鲁棒性、大规模量子优势、通用最优样本复杂度或项目预定的三倍成本加速结论。

复现命令（位于 `experiments/circuit_validation`）：

```powershell
python -B -m unittest -v test_quantum_model
python -B physics_audit.py
```
