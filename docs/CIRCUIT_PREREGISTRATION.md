# 首轮电路级验收：确认实验协议

本协议服务于“采用新参数前，以实际任务验收”的研究。完成的判据是交付完整、公平、可复现的研究；三倍成本优势是待检验的挑战，不是必须得到的结论。正式冻结的权威记录为 `experiments/circuit_validation/confirmation_spec_v1.json`、其 SHA256 文件及源码压缩包。该文件生成之前均属于开发阶段。

## 范围与隐藏真值

研究限定在一个静态三比特物理模型族：受控比特的 X 旋转、另外两比特的固定受控相位（ZZ 与局部 Z 项）、读出翻转，以及可选的马尔可夫退相干。候选和旧参数先固定；目标为既定上下文分布下三比特输出非 000 的概率。定义 Δ 为新失败率减旧失败率，old/new 均未知。

态矢量/Kraus 演化计算评分器真值，并与独立闭式表达交叉核对。验证器只接收公开上下文权重、ε、错误预算、执行预算、匿名标识与付费采样方法，不接收物理参数、失败概率或变化方向。解析生成候选不使用验收样本；此轮没有另行训练候选优化器。

样本由独立 old/new 线路执行产生。直接 A/B 可共享公开随机上下文，但不共享隐藏测量噪声。计数模拟器以二项边际和独立超几何重叠重建完全相同的计数分布；这是模拟加速，不能写成设备加速。不同策略、实例和重复使用不同确定性种子。

## 固定实例和对照

主矩阵为 ε∈{0.01,0.003,0.001}、目标 plus 上下文权重∈{0.2,0.8}、三组噪声配置、改善/恶化两种方向，共 36 格。三组噪声是低读出翻转、标准读出翻转、读出翻转加退相干，并非三个不同硬件平台。

开发主实例的目标变化为 ±1.6ε，确认主实例为 ±1.25ε，均由预设物理参数方程构造。另保留三格 Δ=0、三格 Δ=ε/10，以及两个解析校准盲区世界，共 44 格。后八格是诊断，事先排除于效率评分；它们在两阶段共享物理参数，不能声称为未见过的泛化实例。所有不可行格、失败格和缺失格均须保留并阻止相应通过判定。

预定比较下列八个策略：

| 策略 | 作用 |
| --- | --- |
| `direct_fixed` | 一次预定最终查看的条件精确 McNemar A/B |
| `direct_mixture` | 直接任务配对符号的顺序 Beta 混合检验 |
| `direct_intervals` | old/new 分别构造时间一致区间的简单实现 |
| `joint_trackstop` | 经典联合 KL-GLR 与信息分配基线 |
| `combgame_glr` | CombGame 在线博弈采样的本模型实例，具体改动须明记 |
| `neyman_glr` | 方差驱动分配的候选实现，使用相同联合证书 |
| `balanced_glr` | 均衡分配消融，使用相同联合证书 |
| `calibration_only` | 仅看局部校准的失效诊断，不参加可靠性或领先认证 |

效率对照集合固定为 `direct_fixed`、`direct_mixture`、`joint_trackstop`、`combgame_glr`。候选集合为 `neyman_glr`、`balanced_glr`。这些统计技术有现成文献来源；本轮不将其重新命名为原创算法。原始 CombGame 的实现细节、固定宏批次和停止边界差异见统计方法说明及源码。

## 预算与重复数

同一 ε、上下文权重、噪声分层的两个方向共享固定样本量。设计只读取开发集：取两方向配对 discordance 的较大值，乘 1.10（上限 1），在间隙 ε 和目标功效 98% 下进行数值 McNemar 规划，并保留额外 10% 样本余量。若数值功效不足，按预定规则增量重算。它是开发分布的设计假设，不是全范围功效定理。

固定 A/B 支付 2N 次线路执行；所有策略获得相同的 8N 执行上限。诊断格按相同 ε 的最大主分层预算分配，不使用诊断真值定预算。目标 ε 比确认实例的 1.25ε 更保守；比较必须保留全部强顺序基线，不能只靠相对固定样本的优势得出领先结论。

确认实验固定为 44×8×2,000=704,000 次策略运行。算法的内部错误预算统一为 δ=0.01，不因零变化处的经验认证困难而改小。每个重复最多使用其公共线路预算。

全体统计端点同时覆盖的目标为 95%。安全、功效、成本分别分配 0.02、0.02、0.01；逐格分别除以 3×44×8、2×44×8、2×44×8。不使用的端点额度不回收。

此设计下，每格恰好零错误的单侧安全上界约为 0.54224%；最多 4 次错误可支持 ≤1% 的门槛。预算内正确决定至少 1,938/2,000 次，可支持 ≥95% 功效的门槛。实际报告使用整数二项尾验证的 Clopper–Pearson 端点，不将这些近似说明替代计算。

若真实错误率恰在 1% 边界，有限样本的高置信上界通常超过 1%。这表示经验认证未完成，不反驳正确的 1% 安全定理，更不等于证明方法违规。理论保证、观察到的错误率和置信结论必须分列。

## 成本及判定

所有运行均进入成本统计，包括错误、弃权和异常。主指标为实际线路执行数；另给弃权/超时/异常按满预算计费的保守指标。读取对象数、配置切换、模拟设备时间和主机时间分别保存。每次线路读取三个比特；旧/新线路的归一化时间为 3.2/4.2，切换为 0.1。这是单独声明的成本模型，不是真实芯片计时。

各格成本均值使用有界变量的经验 Bernstein 区间。对全部预设基线同时构造区间，然后用最小基线下界除以候选上界传播加速比下界。资格未证实的基线不能被删除后制造胜出；没有完整资格证据时只报告描述性比较。

效率判定固定使用全部 36 个主实例。总体几何平均要求：实际和惩罚成本的加速比点估计均 ≥3、同时下界均 ≥2；每个 ε、噪声、上下文权重和变化方向分层的点估计均 ≥1。分别报告主格基线资格、候选全部 44 格安全性和 38 格功效；冻结实现还保留更严格的整套闸口，要求候选及全部基线都通过这 44/38 项经验检查，以及完整工程审计。零变化格的经验资格未证实不会使主格成本数据消失。单格三倍不是总体三倍的必要条件；不以选择性删除格来修正结果。

## 开发记录、冻结与停止

开发 v1 的 2,464 次运行比较了前七个策略，每格 8 次，仅用于预算与运行管线检查。两种候选相对每格最快已有基线的成本几何平均约为 0.311、0.233，已经没有三倍优势信号。补充 CombGame 后仍须完整运行预设确认矩阵，不因这个开发结果删掉不利实例或对照。

开发 v2 完成了八策略共 2,816 次运行，每格 8 次，两种候选成本比约为 0.344、0.261。全部原始记录经独立账本重放，2,456 个接受/拒绝证书复算一致；其余是诊断格的弃权。随后在冻结前修正了 CombGame 采样用盒约束的极近边界情形，并完成专门回归测试；这个修正不改变联合停止证书。

正式运行之前固定实例、预算、策略、重复数、种子、分析程序和源码哈希，并归档源文件。原始 gzip JSONL 保留每批动作、执行数、失败计数、计费、最终证书和种子；汇总可从原始记录重建。独立审计逐条重放账本并重算决定证书。既有两轮研究的 manifest 哈希须继续通过。
