# 电路级参数更新验收：统计方法与结论边界

日期：2026 年 11 月 3 日。本文说明本轮软件与电路仿真使用的统计方法，不预设实验结果。

本轮检验一个已经固定的参数更新：在同一公开 workload 上，新参数的失败概率是否低于旧参数。旧、新失败概率均未知，两侧验收数据均需付费。目标是把错误概率、决定能力和测量成本分开核验。这里的 1% 错误概率、95% 决定能力、3 倍点估计及 2 倍置信下界是项目挑战指标，不是国际通用标准，也不是已经取得的结果。

## 1. 目标、观测和成本

设公开上下文为有限集合 \(\mathcal C\)，固定权重为 \(\pi_c\ge0\)，且 \(\sum_c\pi_c=1\)。旧、新参数在上下文 \(c\) 下的失败概率分别为 \(p_{0,c}\) 与 \(p_{1,c}\)。失败事件必须在验收前由电路任务和读出规则定义，不能事后改成更有利的代理指标。目标为

\[
\Delta=\sum_c\pi_c(p_{1,c}-p_{0,c}).
\]

\(\Delta<0\) 表示更新有益，\(\Delta>0\) 表示有害。理论控制错误决定；有限预算决定能力只在预先指定的 \(|\Delta|\ge\varepsilon\) 区域要求达到 95%。接近零时允许弃权，不承诺有限时间完成。审计把 \(\Delta=0\) 时的任何接受或拒绝都算作错误，避免把边界上的任意决定记为成功。

一次旧或新电路执行计一个 shot。两者在同一公开上下文下运行也计两个 shots，条件测量噪声相互独立。共享公开上下文不等于共享隐藏随机噪声；不能复用同一个隐藏 uniform 来人为减少新旧差值的方差。读数对象数、配置切换和模拟设备耗时另行记账，主机运行时间不是硬件时间。

统计证明假定候选和 workload 固定，各上下文下的分布平稳，未来观测服从规定的采样律。电路输出可以有量子相关性；本轮每次执行产生一个已定义失败事件的 Bernoulli 读数，并未把同一次电路的全部读出位假设成独立 Bernoulli。

## 2. 本轮策略和实际对手

实现入口为 [policies.py](../experiments/circuit_validation/policies.py)。正式基线和候选的角色由运行前冻结的配置决定，不能根据测试结果更换。

| 策略 | 采样和停止方式 | 本轮角色与范围 |
| --- | --- | --- |
| `direct_fixed` | 每对独立抽取公开上下文；在预先固定的配对数处做一次条件精确 McNemar 检验 | 直接 workload 固定样本基线 |
| `direct_mixture` | 同样的公开上下文配对，使用 discordant signs 的 Beta 混合检验顺序停止 | 直接 workload 顺序强基线 |
| `joint_trackstop` | 把每个旧/新、上下文组合当作一条臂，按信息分配目标采样，以联合 KL-GLR 停止 | 现有纯探索理论的专化强基线 |
| `combgame_glr` | 每个答案分别使用 AdaHedge，结合 KL 最佳响应、乐观奖励和 C-tracking；固定 block 采样，共用联合 GLR | CombGame 的明确数值专化强基线 |
| `direct_intervals` | 对旧、新边际失败率分别建立混合置信序列，再相减 | 保守的证书形状对照 |
| `neyman_glr` | 依据已付费数据估计方差，按 Neyman 型权重分配；与联合基线使用相同 GLR 证书 | 简洁候选；不声称是新统计算法 |
| `balanced_glr` | 各臂均衡采样；使用相同 GLR 证书 | 简洁候选；隔离采样分配的影响 |
| `calibration_only` | 只测校准上下文，再使用配对检验 | 上下文失配诊断对照；其证书不保证完整目标 workload |

顺序策略在批量检查点判断。批量大小、增长率和固定样本设计均属于冻结方案。改变检查点会改变停止延迟和切换成本，即使统计安全性仍成立，也不能把不同调度的运行成本视为相同。

## 3. 直接配对 A/B 为什么有效

每对实验先独立抽取 \(C\sim\pi\)，再条件独立地运行旧、新参数。定义

\[
b=\Pr(X_0=0,X_1=1),\qquad
c=\Pr(X_0=1,X_1=0).
\]

这里 \(b-c=\Delta\)。记前 \(n\) 对中的 new-only failure 数为 \(B_n\)，old-only failure 数为 \(C_n\)，discordant 总数为 \(K_n=B_n+C_n\)。当 \(b+c>0\) 时，discordant labels 的成功概率为

\[
\theta=\frac{b}{b+c},\qquad
\operatorname{sign}(\Delta)=\operatorname{sign}(\theta-1/2).
\]

同为成功或同为失败的 pair 不提供这个条件符号检验的证据，但其两次执行仍完整计费。

\(K_n=0\) 时混合似然比为 1，固定检验的尾概率为 1，必须弃权；若 \(b+c=0\)，则永远没有 discordance，且 \(\Delta=0\)。

### 3.1 固定样本检验

固定 \(n\) 后，条件于 \(K_n\)，有 \(B_n\sim\mathrm{Bin}(K_n,\theta)\)。在边界 \(\theta=1/2\) 下计算两个精确二项尾概率，每侧分配 \(\delta/2\)。下尾通过则接受，上尾通过则拒绝，否则弃权。单次固定终点的错误保证来自二项尾的单调性。

这个证书不能被反复查看后继续按原阈值停止。样本数只能来自验收前的设计、独立开发数据或已登记的设计假设。分布特定的功效计算是设计辅助，不是对未知噪声的统一保证；也不能读取测试实例的隐藏真值后给基线选择有利样本数。

### 3.2 顺序 Beta 混合检验

对预先固定的 \(r\in\{1/2,1\}\)，令

\[
M_K(\theta)=
\frac{\mathrm B(B+r,C+r)}{\mathrm B(r,r)\theta^B(1-\theta)^C}.
\]

在真实 \(\theta\) 处，这是非负超鞅；真实参数在内部时为鞅。策略在 \(M_K(1/2)\ge1/\delta\) 时，按 \(B-C\) 的符号决定。若真实 \(\theta\ge1/2\)，但当前 \(B<C\) 并错误接受，则 \(M_K(\theta)\ge M_K(1/2)\)；另一方向同理。由 Ville 不等式，任意时刻的错误决定概率至多 \(\delta\)。在 \(\theta=1/2\) 时，两方向共同受同一个越界事件控制。

上述简洁检验需要每对上下文按照固定 \(\pi\) 独立抽样。若自适应挑选上下文后直接混合 discordant labels，它们一般不再对应目标 \(\Delta\)，该证明不能照搬。直接边际置信序列也必须保持每条流的目标上下文采样律；旧、新在同一 pair 中的边际相关性本身不妨碍对两个时间一致覆盖事件作 union bound。

实现与数值边界见 [direct_tests.py](../experiments/circuit_validation/direct_tests.py)。

## 4. 分层联合 KL-GLR 与信息分配

### 4.1 固定上下文仍属于已有理论

令臂 \(i=(v,c)\)，系数为旧臂 \(a_{0,c}=-\pi_c\)、新臂 \(a_{1,c}=\pi_c\)，于是 \(\Delta=a^\top p\)。虽然电路中的均值随上下文变化，每个固定臂的均值仍平稳。对已知权重的读数作缩放，并把全部新臂与全部旧臂作为两个答案，即可映射到组合纯探索。

[Jourdan 等，ALT 2021](https://proceedings.mlr.press/v132/jourdan21a.html) 的 CombGame 研究不同动作集合与答案集合、独立逐分量反馈和信息分配。[Garivier–Kaufmann，2016](https://arxiv.org/abs/1602.04589) 提出经典 Track-and-Stop；[Kaufmann–Koolen，JMLR 2021，第 4 节](https://jmlr.org/papers/v22/18-798.html) 更直接处理一般假设分区的联合 KL-GLR 和时间一致阈值。

`joint_trackstop` 是 Bernoulli 单线性对比的信息分配专化，不能单凭这个实现就称为 CombGame 复现。本轮另行加入 `combgame_glr`，逐项实现后者的学习器、最佳响应、乐观奖励和跟踪调度，具体对应与修改见 4.5。不能仅以“上下文相关”为由排除这些强对照，也不能把有限上下文的重新编号宣称为新统计框架。一般图的向量动作还需相应组合优化 oracle；本轮分层 A/B 的单臂动作不需要求一般图最大权独立集。

### 4.2 安全证书

设每臂已付费观测 \(n_i\) 次，失败数为 \(s_i\)，经验均值为 \(\hat p_i=s_i/n_i\)。记

\[
Z_t=\inf_{q:a^\top q=0}\sum_i n_i\operatorname{kl}(\hat p_i,q_i),
\qquad
m_t=\prod_i\frac{\mathrm B(s_i+r,n_i-s_i+r)}{\mathrm B(r,r)},
\]

\[
R_t=\log L_t(\hat p)-\log m_t,
\qquad b_t=\log(1/\delta)+R_t.
\]

只在 \(Z_t>b_t\) 时按 \(a^\top\hat p\) 的符号决定。对真实向量 \(p\)，\(m_t/L_t(p)\) 是允许自适应选臂的非负超鞅，并且

\[
\log\frac{m_t}{L_t(p)}=
\sum_i n_i\operatorname{kl}(\hat p_i,p_i)-R_t.
\]

若决定符号错误，真实参数位于相反半空间。由 KL 目标的凸性，其到经验点的代价至少为边界最小值 \(Z_t\)。因此错误决定蕴含上述超鞅超过 \(1/\delta\)，给出同一候选下任意检查次数的 \(\delta\) 保证。此证明不需要把经验协方差近似成正态分布。

### 4.3 数值计算的方向

最小化问题的一个可行点给出的是 \(Z_t\) 的上界，不能拿它直接作安全放行证据。本实现用拉格朗日对偶计算下界，并用精确有理数修复边界点得到可行上界。对任意乘子 \(\lambda\) 和近似点 \(q_i\)，凸函数

\[
f_i(x)=n_i\operatorname{kl}(\hat p_i,x)+\lambda a_i x
\]

的切线给出

\[
Z_t\ge\sum_i\left[f_i(q_i)+
\min\{-f'_i(q_i)q_i,\ f'_i(q_i)(1-q_i)\}\right].
\]

实现用 Decimal 向外区间计算这个下界和混合阈值上界；只有下界严格超过阈值上界才作决定。经验均值为 0 或 1 时单独处理。浮点快速预筛只能提前弃权，实际接受或拒绝仍经过完整审核。大阶乘对数使用带已知符号和大小界的 Stirling 余项，不把截断展开当成精确值。这是明确的数值包围计算，不是对 Python 或其运行环境的形式化验证。

### 4.4 三种分配共享同一证书

对内部参数、非零间隙和单臂单位成本，经典信息设计为

\[
I^*(p)=\max_{w\in\Delta_K}\inf_{q:a^\top q=0}
\sum_iw_i\operatorname{kl}(p_i,q_i).
\]

沿缩小目标差的方向选 \(q_i\)，令各臂 \(\operatorname{kl}(p_i,q_i)=z\)，再解 \(a^\top q=0\)。共同 KL 值给出上界；取

\[
w_i\propto\frac{|a_i|}{|\partial_q\operatorname{kl}(p_i,q_i)|}
\]

后，凸优化的 KKT 条件给出相等的下界，故 \(I^*(p)=z\)。`joint_trackstop` 用已观测数据的平滑估计求解此目标，并保留次线性的强制探索。

`neyman_glr` 使用 \(w_i\propto|a_i|\sqrt{\tilde p_i(1-\tilde p_i)}\)；`balanced_glr` 使用等权分配。二者和 `joint_trackstop` 的区别在于获取数据的方式，停止证书相同。平滑、端点数值饱和、批量调度和几何检查点都只影响效率；本轮不据此声称实际有限预算策略或其领先常数最优。

实现见 [kl_trackstop.py](../experiments/circuit_validation/kl_trackstop.py)。

### 4.5 CombGame-AdaHedge 的实现对应

实现见 [combgame.py](../experiments/circuit_validation/combgame.py)，对应 Jourdan 等的 Algorithm 1、3.2–3.3 节及附录 G.1/G.5.1。旧、新两种答案各有一个独立 AdaHedge 学习器；所用更新对应 [de Rooij 等，JMLR 2014 的式 (8) 与 Figure 1](https://jmlr.org/papers/volume15/rooij14a/rooij14a.pdf)。学习率由累计 mixability gap 决定，不依据测试真值调节。单臂动作使组合优化 oracle 退化成对有限坐标的扫描。

计算资源约束在运行前固定为每例最多约 512 个宏轮。公开 shots 上限为 \(B\) 时，固定 \(b=\lceil B/512\rceil\)；一宏轮只选择一条臂，独立执行该臂 \(b\) 次并观察总失败数。这个 block 计数自身构成一参数指数族，其 KL 为 \(b\operatorname{kl}(p,q)\)。因此它是一个明确定义的固定 block 观测模型，不是把变化的批次冒充原论文的单位观测。初始化对每臂执行一个 block，所有执行均收费。每个 block 后检查证书；末尾不足 \(b\) 的剩余预算可执行一次，用于最后的原始计数证书，之后不继续宏轮过程。

每轮用当前答案的学习器给出 \(w_t\)，以一维 KKT 乘子求加权 KL 的最混淆替代参数。对已执行 \(N_i\) 个完整 blocks 的臂，其置信端点由 \(bN_i\operatorname{kl}(\hat p_i,\phi)=f(t-1)\) 给出，乐观奖励取探索项 \(f(t-1)/N_i\) 与端点到替代参数的最大 block KL 两者中的较大者。这里 \(f(t)=\overline W(4\log t)\)，\(\overline W(x)\) 由 \(y-\log y=x,\ y\ge1\) 定义，对应原文两个正参数均取 1。跟踪按原文比例式 \(\arg\min_iN_{t-1,i}/\sum_{s\le t}w_{s,i}\) 选择下一臂，初始化的单位向量也进入累计权重。

本实现明确修改两处：采样的替代概率限于 \([10^{-9},1-10^{-9}]\)，避免经验端点导致无穷 KL 奖励；停止阈值改用 4.2–4.3 节的共同 Beta 混合 GLR。经验均值不平滑，学习器不加入人为最小权重，数值下溢造成的零权重由最佳响应单独处理。KL 乘子和学习器使用 binary64，只有停止使用原始整数计数的向外 Decimal 审核。采样数值修正和固定 block 会影响效率，因此本轮不直接宣称原论文的渐近最优性定理适用于整套实现。错误概率保证由共同证书独立证明；`sampling_metadata` 保存来源、block 规则、截断次数、数值修正及阈值替换。

## 5. Monte Carlo 的同时统计审计

验证器的 \(\delta\) 与评估实验的 \(\alpha\) 是两层不同概率：前者约束一次候选验证的错误；后者约束有限次 Monte Carlo 得出的性能区间。95% 决定能力也不等于 95% 置信水平。

每个冻结的实例与策略组合构成一个 cell，重复数在查看正式结果前确定。cell 内需要独立重复同一冻结实验。不同策略或不同 cell 之间即使使用配对设计，下面的 union bound 也不要求它们相互独立。当前计数型 oracle 的批量划分会改变实际随机数消耗，不能声称它保存逐 shot 的共同随机数路径；其概率律与相应独立执行的计数律一致。

### 5.1 二项端点

对 \(n\) 次重复中的 \(k\) 次错误，单侧 Clopper–Pearson 上界为

\[
U=\operatorname{Beta}^{-1}(1-\alpha;k+1,n-k),
\]

其中 \(k=n\) 时取 1。功效成功数的下界为 \(L=\operatorname{Beta}^{-1}(\alpha;k,n-k+1)\)，\(k=0\) 时取 0。实现的 SciPy 分位点只是初值，返回端点还要通过整数二项尾比较验证方向。

每个 cell 保留 false-accept、false-reject、any-wrong、good-accept、bad-reject 端点。\(\Delta=0\) 的 any-wrong 合并两个决定方向；不适用端点记 NA。错误状态下已经记录的接受或拒绝仍进入安全计数，避免用异常状态掩盖错误放行。功效只把正常完成且方向正确的记录计作成功，弃权、超时和异常都保留在分母中。

这些区间描述所测固定实例的运行概率，不能替代对全部允许参数成立的理论保证。固定重复数区间也不能支持看结果后随意追加重复，直至置信界刚好通过。

理论上错误概率至多 \(\delta=0.01\)，不意味着有限次 Monte Carlo 的同时上置信界一定不超过 0.01。尤其在 \(\Delta=0\) 附近，精确固定检验的实际错误率可能接近名义水平；高置信上界高于 1% 只能记为“Monte Carlo 安全资格未确认”，不能据此宣称已发现违反理论的反例，也不能为通过这项经验门槛而事后缩小内部 \(\delta\)。若要证明实际违规，需要适当分配错误预算的下界超过 1%，或定位一条确实破坏假设或实现的错误。

### 5.2 有界成本

每个 cell 的预算上限为 \(B\)。所有记录的已执行 shots 构成实际成本；正常完成记录保留其实际成本，弃权、超时或异常记录在惩罚成本中按完整预算收费。错误决定的低成本不会被剔除，而是由安全资格单独制约。若记录缺少可审计成本，则审计失败；若成本超出预登记上限，不静默截断，而是保留记录并使对应有界成本证书失效。

对 \(n\ge2\) 次独立成本 \(X_i\in[0,B]\)，令 \(\bar X\) 为全部记录的均值，\(s^2=\sum_i(X_i-\bar X)^2/(n-1)\)。[Maurer–Pontil，2009，Theorem 4](https://arxiv.org/pdf/0907.3740) 应用于 \(X/B\) 和 \(1-X/B\)，给出双侧半径

\[
r=\sqrt{\frac{2s^2\log(4/\alpha)}{n}}
  +\frac{7B\log(4/\alpha)}{3(n-1)}.
\]

将 \([\bar X-r,\bar X+r]\) 截到 \([0,B]\)，覆盖率至少为 \(1-\alpha\)。\(n<2\) 时只返回 \([0,B]\)。实现用精确 moments 和向外 Decimal 计算；零样本方差也不会产生零宽度证书。均值、中位数、样本 p95、最大值和弃权率分别报告，p95 是描述性样本分位数，不是设备尾延迟保证。

### 5.3 错误预算账本

设预登记实例数为 \(J\)，策略数为 \(P\)。本轮分配为

\[
\alpha_{\mathrm{FA}}=\alpha_{\mathrm{FR}}=\alpha_{\mathrm{wrong}}
=\frac{0.02}{3JP},
\qquad
\alpha_{\mathrm{good}}=\alpha_{\mathrm{bad}}=\frac{0.02}{2JP},
\]

\[
\alpha_{\mathrm{actual}}=\alpha_{\mathrm{penalized}}=\frac{0.01}{2JP}.
\]

运行器向每个 cell 传入逐端点预算，审计模块不再次对半，也不回收 NA 的额度。总覆盖失败概率由 union bound 控制在 0.05 以内。内部的双侧成本公式已经分配两个尾部，不再额外计为两个成本区间。

## 6. 成本比、资格不完整和全 cell 汇总

每个效率 cell 必须满足预登记的 \(|\Delta|\ge\varepsilon\) 条件。候选在某个 cell 中未达到安全或功效门槛，不会让该 cell 从效率集合消失。零变化和近边界实例依据验收前的规则单独报告，不在看结果后重新分类。

若每条基线的均值区间为 \([L_b,U_b]\)，候选为 \([L_c,U_c]\)，在共同覆盖事件上，相对最快基线的速度比可保守传播为

\[
\frac{\min_b L_b}{U_c}
\le\frac{\min_b\mathbb E[C_b]}{\mathbb E[C_c]}
\le\frac{\min_b U_b}{L_c}.
\]

分母下界为零时，上界不作有限承诺；缺少必要证据不能算成胜出。实际成本和预算惩罚成本分别计算。

功效下界不足 95% 通常只是“尚未证实合格”，不是“已经证明这条基线无能”。`compare_costs` 因此保留所有预登记基线：只要任何一条的资格未确认，就返回 `baseline_qualification_incomplete`（全部未确认时为 `no_qualifying_baseline`），并阻止资格与速度达标。合格子集上的成本比仍可显示，但明确标注它不能支持完整挑战通过。

`qualification_pass` 表示候选及全部预登记基线资格已确认；`criteria_pass` 在此基础上，还要求该 cell 的实际与惩罚成本速度比点估计均至少 3、下界均至少 2。这个字段明确标注为单 cell 判定。最终项目指标按冻结的全部 eligible cells 与权重计算几何平均，运行器需在该聚合尺度上检查预登记目标，不能误把单 cell 标记替代整体规则，也不能删除未完成或不利的 cell。

当前正式设计以 36 个 main 实例计算总体几何平均：实际与惩罚成本均要求点估计至少 3、同时置信下界至少 2；各主要预登记分层的点估计至少为 1。安全检查覆盖全部 44 个实例，功效检查覆盖 36 个 main 与两个 blind 实例。`calibration_only` 是诊断对照，不进入候选认证。审计模块的 gap 标志只判断 \(|\Delta|\ge\varepsilon\)，运行器还须按预登记的 `benchmark_role` 限定效率集合，不能把 blind 诊断格混入总体速度分数。

实现与测试见 [assessment.py](../experiments/circuit_validation/assessment.py) 和 [test_assessment.py](../experiments/circuit_validation/test_assessment.py)。

## 7. 本轮结果能够支持的范围

这些方法评估已固定候选在已定义任务上的效果，不负责证明调参优化器本身能够找到最优参数。多次候选更新需另立总体风险预算，单候选的 \(\delta\) 不会自动覆盖整个更新序列。

物理上下文效应必须由统一的电路演化和噪声模型产生；手工把 Bernoulli 概率写成上下文的函数，不能单独算作量子物理贡献。有限上下文的静态问题仍有上述现成强方法。本轮可交付的是物理与统计接口的一致性、可复核的验收证书以及对明确对手的公平成本比较。门保真度、逻辑错误率、实机 shots 或墙钟加速，只有在相应任务与硬件实验被实际验证后才能报告。
