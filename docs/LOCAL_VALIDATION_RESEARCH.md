# 隐藏串扰下局部修改的验证成本

日期：2026 年 11 月 2 日。

本轮研究固定一个候选参数修改，只研究如何判断它是否改善完整目标。结论是：在每次只观测一个对象的模型中，可靠接受修改需要支付覆盖未知影响位置的成本；经典顺序检验已能接近这个模型的信息下界。真正需要进一步研究的是未知影响强度、多个弱影响的累积，以及允许并行读出的实验结构。

本轮得到的覆盖下界、KL 下界、顺序检验和最不利边界修正，都是经典统计方法在此问题上的专门化，不作为原创或国际领先成果。其用途是给 FaultTune 建立正确的基线、可复现反例和下一阶段的判断标准。

| 结果 | 状态 | 有效范围 |
| --- | --- | --- |
| 接受局部修改的覆盖与信息成本下界 | 有证明 | 单对象观测、已知观测分布、单隐藏影响 |
| 顺序检验在无异常时的首项最优性 | 有证明，经典方法 | 固定 N，δ 趋于 0，模型准确 |
| 假设异常概率 0.4，实际为 0.3 时错误保证失效 | 有有限事件反证、独立概率计算和仿真 | 固定候选、独立观测、无限预算 |
| 按抵消局部收益的边界构造检验 | 有条件保证及实现 | 已知基线和局部收益、单隐藏影响 |
| 并行读出改变成本的规模关系 | 有界预算下界及简单上界 | 每轮读取全部独立对象的另一种观测模型 |
| 任意未知串扰下的可靠、低成本校准 | 尚未建立 | 不能由上述结果推出 |

## 最小问题与观测模型

候选修改已经固定，已知局部目标减少 a。处理器上有 N 个潜在受影响的监测对象。每个对象在候选参数下产生一个 Bernoulli 坏事件观测。

- H0：所有对象的坏事件概率为已知 p0。
- Hj：只有对象 j 的概率为已知 p1，其他对象仍为 p0。
- 0 < p0 < p1 < 1，0 < a < p1 − p0，0 < δ < 1/2。
- 一次查询选择一个对象，获得一个独立的 0 或 1，成本为一个对象样本。
- 候选、各概率和隐藏位置在整次检验中固定；本轮没有时间漂移。

完整加性监测目标的变化定义为

\[
\Delta F=F_{\rm new}-F_{\rm old}
=-a+(p_1-p_0)\mathbf 1\{H\ne H_0\}.
\]

默认参数为 p0 = 0.1、p1 = 0.4、a = 0.15、δ = 0.05。因此 H0 的候选改善 0.15，每个 Hj 的候选恶化 0.15。

策略只能使用公开参数、已有观测和内部随机数。隐藏位置、真实概率以及完整目标变化只由环境和评分器掌握。这里的隔离是实验接口约定，不是针对恶意 Python 代码的安全沙箱。

无预算截断时，要求

\[
P_0(\mathrm{accept})\ge1-\delta,\qquad
P_j(\mathrm{accept})\le\delta\quad\forall j,
\]

并要求几乎必然给出决定。只要求不错误接受还不够，因为始终拒绝可以零成本满足它。有预算时允许 abstain，必须单独报告，不能计为正确决定。

这个 F 是加性监测代理目标，没有经过量子动力学或硬件校验，不能直接解释为门保真度或逻辑错误率。p0 和 a 的获得成本本轮视为已支付且信息准确；它们未知时，需要重新计入表征成本。完整 FaultTune 引擎没有参与本轮采样。

## 覆盖下界

记 A 为接受候选，Tj 为对象 j 被观测的次数。没有观测 j 的整个决策路径，在 H0 与 Hj 下同分布。因此

\[
P_0(A,T_j=0)=P_j(A,T_j=0)\le\delta.
\]

由此得到

\[
P_0(T_j>0)\ge1-2\delta,\qquad
E_0[\#\text{被观测的不同对象}]\ge N(1-2\delta).
\]

这是期望和逐点概率的下界，不要求每条运行轨迹都覆盖指定数量的对象。如果允许截断，令 a0 = P0(A)，则右端变为 N(a0 − δ) 的正部。大量 abstain 可以减少成本，但同时降低接受有效修改的功效。

## 信息下界

令 d01 = KL(Ber(p0) || Ber(p1))，kl 为两个 Bernoulli 参数的二元相对熵。对任何仅依历史选点的策略，其停止转录满足

\[
\mathrm{KL}(P_0^{\rm transcript}\Vert P_j^{\rm transcript})
=E_0[T_j]d_{01}.
\]

动作选择和停止规则在给定同一历史时相同；只有查询 j 的观测分布不同。把转录映射为接受事件，由数据处理不等式，

\[
E_0[T_j]d_{01}\ge
\mathrm{kl}(P_0(A),P_j(A))
\ge\mathrm{kl}(1-\delta,\delta).
\]

求和得到

\[
\boxed{E_0T\ge
\frac{N\,\mathrm{kl}(1-\delta,\delta)}{d_{01}}.}
\]

停止期望有限时可以直接使用上述恒等式；若 E0T 为无穷，下界自然成立。其方法是经典自适应换测度论证，参见 [Kaufmann、Cappé、Garivier 2016 的 Lemma 1](https://www.jmlr.org/papers/v17/kaufman16a.html)。

预算截断时，若仍对所有 j 满足 Pj(A) ≤ δ，且 a0 = P0(A) > δ，则有 E0T ≥ N kl(a0,δ)/d01。a0 ≤ δ 时，这一论证只给零下界。经验接受率不能未经置信处理就当作已知 a0 代入严格证明。

## 达到正确性要求的顺序检验

对对象 j 维护似然比

\[
L_j=\prod_{s:I_s=j}
\frac{p_1^{Y_s}(1-p_1)^{1-Y_s}}
{p_0^{Y_s}(1-p_0)^{1-Y_s}}.
\]

若任一点 Lj ≥ N/δ，拒绝候选。若某点 Lj ≤ δ，将它标记通过，并停止测量该点。所有点通过才接受候选；预算耗尽而未决定时返回 abstain。

H0 下各 Lj 是非负鞅，Ville 不等式和并集界保证总体错误拒绝概率不超过 δ。Hj 下 1/Lj 是非负鞅，接受候选必然要求异常点到达下界，所以错误接受概率也不超过 δ。下界无需额外除以 N。

该保证允许根据历史选择下一个对象。只测尚未决定的点，并在通过后冻结，即可在有限 N 下几乎必然终止。

以下 T 指无预算截断的总样本数。令 b− = log((1−p0)/(1−p1))。单点 log LR 在 H0 下的平均增量为 −d01，越过下界的超越量最多 b−。Wald 恒等式给出

\[
\boxed{
\frac{N\,\mathrm{kl}(1-\delta,\delta)}{d_{01}}
\le E_0T\le
\frac{N[\log(1/\delta)+b_-]}{d_{01}}.}
\]

因此固定 p0、p1、N 时，δ 趋于零的首项匹配；H0 成本不需要额外的 log N 因子。这属于经典顺序概率比检验的性质。直接相关的先行工作包括 [Malloy–Nowak 的稀疏顺序检验](https://arxiv.org/abs/1212.1801)；其支持恢复问题与本轮接受或拒绝候选的问题不同，不能直接混用全部最优性声明。

实现比较逐点完成的 sequential_scan 和对未决点轮询的 sequential_round_robin。它们使用同一组逐点随机流。在接受路径上，各点消耗的观测及总样本量相同；在拒绝路径上，发现异常的顺序会改变成本。轮询会冻结已经通过的点，并非故意重复测量的弱基线。

## 名义模型下的实验

主实验包含 N = 8、32、128；无异常、首位、中间、末位异常四种情况；七种策略；每组 200 次，共 16800 次试验。不同策略共享每个对象的第 k 个随机数，不共享完整目标。随机种子和输入参数保存在结果中。

固定采样有两类基线。full_fixed 和 fixed_scan 用 Hoeffding 界设定样本量；fixed_exact 和 fixed_exact_scan 在“各点使用相同样本数、任一点超过同一计数阈值就拒绝”的设计类中，搜索最小样本数。后者按二项分布计算总体两类错误，使用双精度及保守余量，并非区间算术证明，也不是所有固定预算策略中的最优性证明。

| N | 理论 E0T 下界 | 顺序扫描的 DP 数值预测 | 顺序扫描的仿真均值 | fixed_exact 的样本量 |
| --- | ---: | ---: | ---: | ---: |
| 8 | 93.69 | 110.69 | 113.045 | 264 |
| 32 | 374.74 | 445.32 | 444.335 | 1248 |
| 128 | 1498.96 | 1784.22 | 1764.140 | 5760 |

这里的减少是经典顺序测量相对于指定固定采样基线的结果，不是 FaultTune 相对于国际最佳校准系统的优势。N = 128 时，顺序扫描的 DP 成本预测约为信息下界的 1.19 倍。

独立的 audit_math.py 不调用仿真策略，而是传播单点似然比随机游走的未吸收概率。由各点的退出概率和独立性，计算完整判决的概率以及扫描成本的数值预测。截断剩余概率通常约 10⁻¹⁴ 每点；它只界定概率截断误差，不直接界定期望误差。所有计算还受浮点误差影响。

例如 N = 128，DP 预测总体错误拒绝约 2.744%，存在单异常时错误接受约 3.980%。200 次小样本试验的比例会波动；结果附逐项 Wilson 区间，它们不是对所有组同时成立的置信界。概率保证来自模型下的证明，不能由某一批仿真“认证”。

## 模型失配的反例与最小修正

保持策略假设 p1 = 0.4，但把实际异常点的概率改为 0.3。真实完整变化为 −0.15 + (0.3−0.1) = +0.05，候选仍然有害。

保证失效有一个不依赖仿真的反证。旧似然比每看到零就乘以 2/3；连续八个零使 (2/3)⁸ < 0.05，该点被错误标记通过。实际异常点出现这八个零的概率是 0.7⁸。其他正常流全部通过的概率至少 1−(N−1)δ/N，并与异常流独立。因此无预算截断时

\[
P_{p=0.3}(A)\ge
0.7^8[1-(N-1)0.05/N]
\ge0.0547656095>0.05.
\]

实际错误率更高。N = 128 的 1000 次独立失配试验中，旧检验错误接受 234 次，即 23.4%，95% Wilson 区间为 20.88% 至 26.12%；独立 DP 预测为 23.251%。

一个经典最不利边界修正是用 q = p0 + a = 0.25 代替猜测的 p1。单隐藏影响只有在 p ≥ q 时才会抵消局部收益。用 Ber(q)/Ber(p0) 构造 LR，则对所有 p ≥ q，

\[
E_p[1/r(Y)]
=1-\frac{(p-q)(q-p_0)}{q(1-q)}\le1.
\]

异常点的 inverse LR 成为非负超鞅，恢复统一的错误接受控制。H0 下错误拒绝控制也保持。stress_probe.py 中的 harm_boundary_scan 实现这一修正。

| N = 128 的独立压力实验，每格 1000 次 | 旧 sequential_scan | harm_boundary_scan |
| --- | ---: | ---: |
| 无异常时平均测量量 | 1780.184 | 5358.878 |
| 实际异常概率 0.3 时错误接受 | 234 次，23.4% | 6 次，0.6% |
| 对应错误接受的 DP 数值预测 | 23.251% | 0.832% |
| 实际异常概率 0.3 时平均测量量 | 462.965 | 87.562 |

代价主要体现在确认安全候选上。针对 q = 0.25 的更大假设类，N = 128 时 H0 理论期望下界为 4681.17，上界为 5613.98，修正检验的 DP 预测为 5346.49。因此这个成本增加有信息论原因，不能只视为实现低效。

修正仍有明确边界：p0 与 a 必须准确已知；只有一个隐藏受影响点；对所有 p ∈ (p0,q) 的实际有益修改，没有统一的接受功效保证。多个较小的影响可能各自小于 a、合计却超过 a，当前规则没有覆盖这种情况。候选在测量过程中改变、设备继续漂移或基线估计错误，也需要新的论证。

## 有限预算不能只看错误率

另做 N = 32、每次最多 300 个对象样本、四种策略、四种情况、每组 500 次，共 8000 次试验。无异常时，sequential_scan 接受 0 次、拒绝 9 次、abstain 491 次。

1.8% 的错误拒绝率不能单独说明这个策略已完成任务：它没有接受任何有效修改。此实验不满足前面完整 δ 正确检验所需的接受功效，不能用 300 与 374.74 的下界比较来声称突破下界。结果分别保留 accept、reject、abstain。

## 并行读出改变成本模型

单对象模型的 N 因子是总对象样本成本，不能直接解释成硬件实验轮数。一次真实电路执行可能同时给出多个监测对象的读数。

考虑另一理想化模型：一轮同时读取全部 N 个独立对象，最多 B 轮。令 v = (p1−p0)²/[p0(1−p0)]，Q 为 N 个单异常模型在完整 B 轮数据上的均匀混合分布。不同异常点似然比的交叉二阶矩为 1，同一点二阶矩为 (1+v)^B，所以

\[
\chi^2(Q\Vert P_0)=\frac{(1+v)^B-1}{N}.
\]

两侧正确性要求 TV(P0,Q) ≥ 1−2δ。结合 TV ≤ ½√χ² 得

\[
\boxed{B\ge
\frac{\log[1+4N(1-2\delta)^2]}{\log(1+v)}.}
\]

这是一条固定最大轮数的下界，不是点查询顺序检验的期望下界。简单固定采样给 O(log(N/δ)) 的轮数上界；这里没有证明最优常数。默认 N = 128 时，上式要求 B ≥ 8.70，即至少 9 轮；按二项分布设定的固定阈值可以在这个理想化独立全读出模型中用 45 轮完成检验，但总读数仍是 128×45。

一般实验 e 可以读取集合 Se，成本 ce。逐替代 KL 论证给出必要覆盖约束

\[
d_{01}\sum_{e:j\in S_e}E_0[N_e]
\ge\mathrm{kl}(1-\delta,\delta)\quad\forall j.
\]

最小化总成本 Σe ce E0[Ne] 得到一个加权覆盖下界。但单独使用它可能漏掉多替代混合造成的额外障碍，正如全读出模型需要上述混合论证。相关读出、测量串扰和电路布局限制均尚未建模。

## 下一步研究问题

本轮已把“未知单点影响的简单顺序检验”落实为一个可复现底座；没有理由把它继续包装为新算法。下一步优先处理一个更具体的问题：

> 给定图上可实现的并行监测电路、未知但稀疏的多个受影响因子，怎样以受控错误概率判断它们的总损失是否超过已知局部收益，并最小化测量轮数与读出成本？

第一批扩展应允许两个或四个弱影响共同使修改变差；允许“一轮读多个点”，同时单独计量电路轮数、对象样本数及切换成本。基线至少包括完整验证、固定合法分组、经典顺序方法和多保真采样。判定目标是总变化的符号，不预先要求恢复全部异常位置。

继续投入的条件是找到利用实验结构的可验证优势，并将它与经典异常检测或多保真方法区分开。若优势来自免费获得真实图、真实基线、真实漏项界，或把并行读出错误地按串行计费，就应修正模型再比较。

## 先行工作与引用边界

- [Malloy 和 Nowak，Sequential Testing for Sparse Recovery，2014](https://arxiv.org/abs/1212.1801)：逐坐标顺序检验、非对称阈值及未知异常分布问题。其部分下界对算法类有额外限制。
- [Castro，Adaptive sensing performance lower bounds，2014](https://arxiv.org/abs/1206.0648)：自适应感知的信息下界；原模型以 Gaussian 观测和精度预算为主。
- [Kaufmann、Cappé 和 Garivier，2016](https://www.jmlr.org/papers/v17/kaufman16a.html)：停止转录的换测度工具。
- [Naghshvar 和 Javidi，Active sequential hypothesis testing](https://arxiv.org/abs/1203.4626)：依据历史选择观测动作的通用框架。
- [Cohen 和 Zhao，Active Hypothesis Testing for Quickest Anomaly Detection](https://arxiv.org/abs/1403.1023)：异常搜索与采样调度；基本问题预设异常存在。
- [Zhao 等，2026](https://arxiv.org/html/2601.10203v2)：量子频率配置中的局部目标、BCD 和拓扑排序。
- [Optimal Multi-Fidelity Best-Arm Identification，2024](https://arxiv.org/abs/2406.03033)：不同成本与精度的观测选择、实例相关成本下界。
