# 量子调参验收的定量研究目标

日期：2026 年 11 月 3 日。

FaultTune 的研究主线是给量子调参加一道验收关：采用新参数前，用尽量少的实验判断实际任务是否受益。首个竞争目标定为 **误放行不超过 1%，明显有益更新的预算内通过率至少 95%，验证成本争取降低到最强合格对照的三分之一**。

这些数值是项目拟定的研究门槛，不是国际公认标准，也不是现有结果。达到门槛后，还需结合问题的新颖性、最强可比方法、未用于开发的测试结果和独立复现，判断能够支持多大范围的领先表述。[机器可读指标](../experiments/acceptance_benchmark/criteria_v0.json)与本说明共同构成验收草案；具体模型、测试集及预算冻结后才能执行正式验收。

## 三项指标必须同时通过

固定修改前参数、候选参数、目标电路或任务分布，以及成功与失败的判据。定义

\[
\Delta=p_{\mathrm{fail,new}}-p_{\mathrm{fail,old}}.
\]

两个失败概率均未知，必须使用付费观测估计。候选在验收开始前冻结，验收数据独立于候选选择数据。模拟器的精确概率仅供独立评分器使用。

| 指标 | 初始正式目标 | 比较口径 |
| --- | --- | --- |
| 误放行风险 | 对 Δ≥0，接受概率≤1% | 保证覆盖全部声明模型；有限仿真另作逐实例统计检查 |
| 有益更新通过率 | 对 Δ≤−ε，预算内接受概率≥95% | 避免总是拒绝或弃权制造安全性与低成本 |
| 有害更新识别率 | 对 Δ≥ε，预算内拒绝概率≥95% | 同时检查有害更新能否在预算内得到明确决定 |
| 错误拒绝 | 对 Δ≤0，拒绝概率≤1% | 使用同时有效的差值区间可一并控制两侧错误 |
| 验证成本 | 固定测试集上的加速比几何平均≥3 | 对照同信息、同错误、同功效、同预算的最强合格方法 |
| 成本证据强度 | 加速比同时置信下限≥2 | 不能只展示点估计或最有利实例 |

ε 是预先规定的最小有意义改变量，拟测试绝对失败概率间隙 0.01、0.003、0.001。例如 ε=0.001 表示失败率至少下降 0.1 个百分点。ε 以下的候选仍受误放行约束，但不要求在有限预算内作出决定。不能在看到结果后扩大 ε，把困难实例移出评价。

三个数字的依据不同：1%规定风险容忍度，95%规定实际可用性，3 倍规定值得投入研究的成本优势。它们没有自动对应“国际领先”的认证。若某个应用需要每次误放行低于 0.1%，应重新设计和比较该风险水平下的全部方法。

## 成本比较和合格对照

主成本为执行的验收电路次数，包括 old 与 new 两边、验证器特有的预表征或训练、重试、丢弃数据和初始化观测。共享候选优化器的成本另外报告；只证明验收成本下降，不能称整个校准流程同倍加速。

所有运行都进入均值，包括错误和弃权，不能只统计正确决定或已经结束的运行。额外报告一个保守成本：有决定时计实际成本，弃权时计满预算；该口径也须达到加速比点估计≥3、同时置信下限≥2，以及每个主要分层点估计≥1。计满预算是评分罚项，不可写成实际执行过这些实验。超时、异常和未完成运行同样计入未通过，并按满预算评分；数据泄漏、非法动作或证书错误还会直接导致工程审计不通过。

另外记录读取对象数、配置切换次数、模拟设备执行时间和主机计算时间。模拟设备时间按准备、门操作、等待、读出、重置和切换的预定成本计算；并行时间按合法资源时间线计算。要声称设备耗时领先，还需在预先指定的成本权重范围内保持优势。Python 运行时间不能替代设备时间。

至少纳入以下对照：

1. **直接目标任务的固定样本 A/B 验证。** 同时估计 old/new 失败率，预先设计样本量与功效。
2. **直接目标任务的顺序 A/B 验证。** 使用时间一致区间或有效顺序检验，允许提前决定，并采用合理批量调度。
3. **当前最强的适用方法。** 若使用局部表征与模型外推，必须计入建模数据成本并检验外推假设；当前静态求和问题应保留批量 pooled sweep 作为对照。

候选生成器及其数据对所有验证器保持一致。对照方法的调参在开发集上完成；正式测试必须冻结实现、超参数和预算。不能用已知不具备误放行保证的单影响检验当作“最强方法”。

加速评分只用于预注册且 |Δ|≥ε 的实例。不变和近边界实例继续做安全与成本检查，但在正式评估前就规定不进入加速评分，避免利用无功效承诺的廉价弃权制造优势。对符合这个条件的固定实例 i，令 C 为包含全部运行的平均成本，定义

\[
R_i=\frac{\min_{b\in\mathcal B_{\rm qualified}}C_{b,i}}{C_{\rm FaultTune,i}},
\qquad R=\exp\left(\frac1M\sum_{i=1}^M\log R_i\right).
\]

正式目标为 R≥3，每个预先定义的主要模型分层的点估计 R≥1，并给出同时置信下限。为避免挑选最强对照后的统计偏差，所有对照的成本均值一起构造同时区间；用对照的成本下界及 FaultTune 的成本上界传播出保守加速比下界。有限预算使单次成本有界，可以使用适当的有界变量浓缩界。探索性 bootstrap 可帮助观察，但不能自行替代正式同时覆盖论证。

如果有对照未满足安全或功效要求，保留其结果并标明原因；不得因 FaultTune 在该实例失败而删除实例。若没有合格强对照，该实例不能给出领先评分。均值、median、p95、最大成本和弃权率全部留档。

## 有限实验怎样验收概率

理论保证与经验检查分别给出。理论的 1% 要覆盖明确声明的模型族；有限仿真只能给被测试实例或已注册测试分布的统计结论。

误放行率使用单侧精确 Clopper–Pearson 上限，有益更新通过率使用单侧精确下限。以整个统计审计的 95% 同时置信为目标，初始分配为：安全指标 α=0.02、功效指标 α=0.02、成本指标 α=0.01；每一类内部继续按所有端点数量分配。置信水平和算法自身的 1% 误判概率是不同概念。

作为直观尺度，若只认证 K 个安全端点、共享 α=0.05，恰好零错误时所需最少独立重复数为

\[
n\ge\left\lceil\frac{\log(0.05/K)}{\log(0.99)}\right\rceil.
\]

| 同时认证的安全端点 K | 每个端点零错误时至少需要的重复数 |
| --- | ---: |
| 1 | 299 |
| 24 | 615 |
| 60 | 706 |
| 120 | 775 |

这张表是单独分配 α=0.05 的示例，不是上述安全、功效、成本联合审计的实际运行计划。当前每格 100 次零错误，在单格单侧 95% 下也只支持约 2.95% 的上限，不能据此通过 1% 验收。

这些最小重复数也不代表有很高概率通过验收：若每个端点都必须恰好零错误，许多端点一起通过可能非常困难。应先规定设计余量，例如实际目标误放行≤0.1%、有益更新通过率≥98%，再用允许非零错误的二项分布功效分析确定重复数。重复数在正式测试前固定；不能看到结果不达标就继续采样，直到普通固定样本区间通过。

例如，仅认证 60 个误放行端点和 60 个好候选通过率端点，每类共享 α=0.02，每端点固定 3,000 次：误放行不超过 12 次、好候选接受至少 2,890 次，分别满足 1% 和 95% 的精确单侧门槛。若真实表现达到前述 0.1% 与 98% 的设计余量，二项功效计算给出的整套通过概率并合下界约为 99.90%。这是特定设计性能下的验收通过功效；不是统计置信度，也未认证额外的坏候选拒绝、错误拒绝或成本端点。实际端点数确定后需要重新分配和计算。

## 基准覆盖与泛化

正式仿真基准争取覆盖至少 3 类可解释的物理机制、2 类任务及 3 个系统规模。测试中包含明显改善、明显恶化、不变、近边界，以及校准上下文与目标任务不同的实例。额外保留未用于算法设计的上下文和参数区间。

每种上下文效应必须由同一个电路演化或噪声模型推出；不能直接手工给不同测量动作指定有利的 Bernoulli 概率，然后称为物理贡献。小规模实例由独立精确或可控误差求解器计算目标真值。大规模扩展另行说明所用结构和求解误差，不把大量标量对象等同于同等数量的完整量子比特。

必需的机器审计要求为：候选选择与验收样本零交叉、零非法并行、零漏计执行、零证书与决定不符，以及策略不能读取隐藏真值。old/new 两个配置不能通过共享模拟器内部随机噪声获得实际不可执行的免费配对优势；跨算法复用同一分支的随机流用于公平比较，则可以明确记录。

日志必须保留候选与 old 参数哈希、目标电路与失败判据、选择和验收数据标识、每批配置与执行数、失败计数、置信区间、错误预算、停止原因、全部成本，以及源码、模拟器、噪声和成本模型版本。独立复现应能据此重新得到结论，而非只读取一张汇总表。

## 哪些结果值得争取领先表述

**仿真性能方向：** 在上述合格基准和同时置信检查下达到 3 倍目标，并在未用于开发的实例上保留优势。加强目标是在预注册的重要模型分层达到 10 倍；只对该分层表述，不能外推为全部量子校准普遍加速。

**理论方向：** 给出校准信息足够或不足以验收目标任务的明确条件，以及同一观测、错误和功效约束下的必要成本与可达成本。先争取同阶，再争取明确模型族中的首项最优。允许弃权的有限预算试验，不能直接套用要求无限预算完整终止的下界。

**复现方向：** 完整开放协议、基线与审计材料，并取得独立实现或外部复现。软件与仿真证据支持相应范围的结论；硬件上的门质量、逻辑性能和运行时间需要另行验证。

倍数本身不能跨任务比较。例如 [Snake 的 68 比特校准研究](https://arxiv.org/html/2308.02321v3)比较局部修复与全量重优化；[Google 的 QEC 信号强化学习校准](https://arxiv.org/html/2511.08493v4)考察持续运行下的逻辑稳定性。它们不能直接作为验证器电路次数的同口径基线。[同时 GST 的上下文串扰分析](https://doi.org/10.1103/PRXQuantum.2.040338)已经展示该现象及统计分析；新颖性必须落在新的可辨识条件、代价或方法，而非仅展示上下文依赖。[局域依赖下自适应校准的理论预印本](https://arxiv.org/html/2608.05686v2)也是规模结论需要逐假设比较的参照。

## 立即推进的最小里程碑

先构造一个 3 比特、固定含 ZZ 耦合并有旁观比特驱动的小电路模型。目标是在预先限定的模型族中检验：指定校准菜单下的完整观测分布相同或严格量化地接近，候选在目标任务中的效果却异号。精确不可辨识与近似不可辨识分别论证；未找到例子只说明此次搜索未找到支持。

随后加入一个匹配运行上下文的审计动作，先实现未知 old/new 失败率的直接 A/B 顺序验收。第一版可分别给 old/new 分配时间一致区间，再取差值区间 `[L_new−U_old, U_new−L_old]`；只在总上界<0 时接受，总下界>0 时拒绝，预算耗尽则弃权。补充观测能够解除歧义，并不自动意味着比直接 A/B 更省，后者仍需实际比较。

这一里程碑的工程通过条件是：物理模型一致、未知 old/new 的观测均付费、候选选择与验收数据零交叉、隐藏真值隔离、证书可独立重算，以及动作与成本账本完整；不预先要求达到 3 倍。是否找到上下文分离实例作为研究结果单列，负面搜索结果不能替代上述工程条件。得到可比较的电路实例后，再冻结完整基准、成本权重、每实例预算、统计端点数和重复数，执行正式竞争验收。

多轮校准另设阶段目标。若希望一次完整校准流程的误放行风险也不超过 1%，需要条件有效的逐更新保证及总和≤0.01的错误预算；单次 1% 不能直接重复解释为整个流程 1%。
